# 宝可肉鸽 · Poké Rouge

最多 **4 人联机** 的宝可梦像素风割草肉鸽游戏。玩法参考《土豆兄弟》（Brotato），主角换成了宝可梦；
界面风格参考 [pokesurvivor](https://github.com/JPTER78/pokesurvivor)（PMD 蓝色双白边对话框 + 像素精灵），
地图是初代/二代风格的像素道路、森林、山洞与宝可梦之塔。

- 一局 20 波：普通波次从 30 秒（第 1 波）逐步增加到 60 秒（第 19 波），**存活到倒计时结束**即可过关；首领波 90 秒
- 第 10 波首领 **卡比兽**，第 20 波最终首领 **梦幻**；第 5/8/12/14/15/17/18/19 波有精英（大针蜂、大岩蛇、耿鬼）
- 技能自动瞄准释放；升级可选强化、**领悟新技能**；等级够了以后波次结束时询问是否**进化**（可以按 B 取消，之后随时再进化）；每波结束后进入**商店**
- **三档难度**：简单 / 普通 / 困难（敌人数量、血量、伤害、移速逐级叠加，并有群聚波与额外精英），通关上一档解锁下一档，**通关困难模式解锁超梦**
- 局外成长：用星之沙在「大木研究所」永久提升所有宝可梦的 HP / 物攻 / 特攻 / 物防 / 特防 / 速度等
- 通过**成就解锁**新的宝可梦
- 联机：**联机大厅**里能看到所有公开房间和当前在线人数，也可以创建（公开/私密）房间、输入 **5 位房间号**或打开邀请链接加入
- 倒下的队友身边会出现绿色**救援圈**，站进去 2.5 秒就能把它救起来
- 支持 **Xbox / PlayStation 手柄**

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm run build      # 构建前端 (dist/) 与服务器 (dist-server/)
npm start          # 启动服务器，默认 http://localhost:8787
```

打开浏览器访问 `http://localhost:8787`。单人模式完全在浏览器内运行；「创建房间 / 加入房间」通过同一个服务器联机。
局域网内的朋友访问 `http://你的IP:8787` 即可一起玩。

开发模式（前端热更新 + 服务器自动重启）：

```bash
npm run dev        # 前端 http://localhost:5173 ，/ws 自动代理到 8787 端口的服务器
```

其它命令：

| 命令 | 说明 |
|---|---|
| `npm test` | 单元测试 + 无头整局模拟 + WebSocket 联机集成测试 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npx tsx tools/balance.ts 4 1` | 平衡性报告：机器人用每只精灵各打 4 局（第二个参数为人数） |

### 部署到公网

服务器是一个普通的 Node 进程（HTTP 静态文件 + WebSocket `/ws`），任何支持 Node/WebSocket 的平台都可以部署
（Render、Railway、Fly.io、自己的云服务器等）：

```bash
npm ci && npm run build && PORT=8787 npm start
```

也可以用仓库里的 `Dockerfile`：`docker build -t poke-rouge . && docker run -p 8787:8787 poke-rouge`。

如果前端和服务器分开部署（例如前端放静态托管），构建前端时指定服务器地址：
`VITE_SERVER_URL=https://你的服务器域名 npm run build:client`。

环境变量：`PORT`（默认 8787）、`HOST`（默认 0.0.0.0）、`MAX_ROOMS`（默认 300）、`STATIC_DIR`（默认 `dist/`）、
`POKE_DEBUG=1`（开启测试用的调试指令，正式部署不要开）。

`GET /api/stats` 返回在线人数（打开着游戏页面的连接数）、游戏中人数与房间数；`GET /api/rooms` 返回公开房间列表。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | `WASD` / 方向键；手机上在屏幕任意位置拖动出现摇杆 |
| 技能 | 自动释放（瞄准最近的敌人） |
| 暂停（仅单人） | `Esc` / `P` |
| 手柄（Xbox / PS） | 左摇杆或十字键移动；菜单和商店里移动选择框，A/× 确认，B/○ 返回或取消进化，X/□ 刷新商店，Y/△ 出发，Start/Options 暂停 |

界面会随窗口大小等比缩放（大屏幕上字和按钮同样清晰）；手机需要横屏游玩，竖屏时会提示旋转并尝试全屏锁定横屏。

## 游戏设计

### 初始精灵（5 只）

数值按原作种族值设定（HP / 物攻 / 物防 / 特攻 / 特防 / 速度），并有各自的被动：

| 宝可梦 | 属性 | 技能栏 | 本系加成 | 特色 | 解锁 |
|---|---|---|---|---|---|
| 小火龙 → 火恐龙 → 喷火龙 | 火（喷火龙 火/飞行） | 4（最终形态 5） | 火系 +20% | 猛火（低血量火系 +50%）、暴击 +5% | 初始 |
| 杰尼龟 → 卡咪龟 → 水箭龟 | 水 | 4（最终形态 5） | 水系 +20% | 激流、双防 +10%、护盾 +50% | 初始 |
| 妙蛙种子 → 妙蛙草 → 妙蛙花 | 草/毒 | 4（最终形态 5） | 草系 +20% | 茂盛、回复 +4、治疗 +30%（可治疗队友） | 初始 |
| 皮卡丘 → 雷丘 | 电 | 5 | 电系 +20% | 静电（接触麻痹）、电气球（未进化物攻/特攻 +15%），用商店的雷之石进化 | 成就：到达第 5 波 |
| 超梦 | 超能力 | 3（觉醒后 4） | 超能力系 +30% | 压迫感（附近敌人减速），无法进化，Lv10/Lv18 基因觉醒 | 成就：通关困难模式 |

小火龙/杰尼龟/妙蛙种子在 Lv7 与 Lv14 可以进化：和原作一样，进化在战斗（波次）结束后发生，可以选择取消，之后的商店里随时可以再进化；携带「不变之石」则永远不进化并获得加成。每只精灵都有自己的升级技能表（例如小火龙 Lv12 领悟喷射火焰、Lv23 领悟大字爆炎）。

### 战斗数值

- **物理技能**吃「物攻」（偏近身：撞击、火焰牙、藤鞭、铁尾……），**特殊技能**吃「特攻」（偏远程：火花、水枪、十万伏特……），对应土豆兄弟的近战/远程
- 敌人的**接触伤害**由「物防」减免，**弹幕与爆炸**由「特防」减免
- 与自身属性一致的技能有 **1.5 倍本系加成**；保留完整 18 属性克制表但大幅弱化：效果拔群只多 10%（双重克制 20%），效果不好少 10%，免疫/双重抵抗少 20%
- 副属性：技能急速（冷却缩短）、暴击、技能范围、闪避、生命回复、吸血、幸运、收获、对小怪/对首领伤害、反伤等
- 50+ 个技能，分为初级 / 中级 / 高级 / 究极四个等级，形态有弹体、近身扇形、光束、范围冲击、连锁闪电、定点打击、环绕、持续区域、回复、护盾、强化
- 技能特效参考 pokesurvivor 的做法：每种属性一套 5 色调色板，用代码生成带描边的像素小图（火焰、水滴、叶片、闪电、冰晶、暗影球……），配合按材质的拖尾粒子、像素挥砍弧、分段光束与像素点冲击波

### 难度

| 难度 | 敌人数量 | 敌人血量 / 伤害 | 移速 | 首领血量 | 其它 | 解锁 |
|---|---|---|---|---|---|---|
| 简单 | 标准 | 标准 | 标准 | 标准 | — | 初始 |
| 普通 | +20% | +25% / +25% | +8% | +35% | 群聚波（刷怪翻倍）、额外精英 | 通关简单 |
| 困难 | +35% | +50% / +50% | +15% | +70% | 更多群聚波与精英，最终波耿鬼助阵 | 通关普通 |

难度带来的额外敌人不会额外掉糖果（每波收入不变，只增加危险）；星之沙按难度 ×1 / ×1.4 / ×1.8 结算。

### 商店

每波结束后：先选升级强化（营养剂、PP 提升剂、聚气……），再打开道具球，然后进入商店：

- **道具**（126 种，每种都有自己的像素图标）：取自宝可梦系列的携带物品、树果、薰香、石板、性格薄荷、精灵球、营养剂、
  野外道具与宝可梦卡牌（TCG）的宝可梦道具，效果按土豆兄弟重新设计——
  - 增减敌人数量：引虫香水 / 白银香水 / 黄金香水、白色玻璃哨（敌人更多，经验金钱也更多）；除虫喷雾 / 白银喷雾 / 黄金喷雾、黑色玻璃哨、清净薰香、洁净之符（敌人更少）。联机时全队叠加
  - 先制之爪（技能急速）、力量头带（对小怪伤害）、讲究腰带（对首领伤害）、讲究头带/眼镜/围巾（大幅提升但技能栏 -1）、
    气势披带、气势头带、活力碎片/活力块（复活）、防尘护目镜（免疫孢子减速与毒雾）、光之黏土（护盾增强）、大根茎（回复增强）、
    不变之石、进化奇石、电气球（皮卡丘）、黑色铁球、后攻之尾、银色/金色王冠、自行车、闪耀护符……
- **招式学习器**：学习其它宝可梦的技能，越贵越高级（初级 ≈ ₽22 … 究极 ≈ ₽145，随波次涨价）；重复购买会强化已有技能
- 可**锁定**商品、花钱**刷新**；技能栏满时可选择遗忘旧技能

### 联机

- 服务器权威模拟：每个房间在服务器上跑同一套游戏逻辑，客户端只上报自己的位置与操作；位置有速度校验
- 二进制快照 15 次/秒 + 插值平滑；本地玩家即时移动
- 敌人数量与血量随人数提升；倒下的队友身边有救援圈，站进去 2.5 秒救起（多人一起救更快），全员倒下才算失败；波次结束时所有人自动复活
- 联机大厅：每个打开游戏的页面保持一条连接，用于统计在线人数和推送公开房间列表；房主可以设为私密房间（只能用房间号加入）
- 房间内最多 4 人，房主选择难度并开始游戏；商店阶段等全员准备（联机时 150 秒后自动开始）

### 局外成长与成就

- 每局按完成波次、击败数、首领、是否通关结算**星之沙**（联机 +20%）
- 「大木研究所」14 项永久强化（HP、物攻、特攻、物防、特防、速度、暴击、急速、回复、幸运、经验、拾取、开局金钱、商店免费刷新）
- 26 个成就，奖励星之沙并解锁皮卡丘、普通/困难难度与超梦
- 存档保存在浏览器 localStorage

## 项目结构

```
src/shared/        前后端共用：属性克制、精灵/技能/道具/敌人/波次数据、局外成长与成就、协议、房间
src/shared/sim/    游戏模拟（波次、刷怪、敌人 AI、技能、伤害、升级进化、商店）
src/server/        Node 服务器：静态托管 + WebSocket 房间
src/client/        浏览器端：渲染（像素瓦片、PMD 精灵动画、特效）、HUD、商店与菜单界面、音效
tests/             测试与对局机器人
tools/             素材导入、平衡性报告
```

素材导入：`node tools/import-sprites.mjs /path/to/pokesurvivor` 会从 pokesurvivor 仓库复制本作用到的精灵表并生成元数据与署名。
新增宝可梦时把图鉴编号加到脚本的 `DEX` 列表里重新运行即可。
