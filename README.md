# 宝可肉鸽 · Poké Rouge

最多 **4 人联机** 的宝可梦像素风割草肉鸽游戏。玩法参考《土豆兄弟》（Brotato），主角换成了宝可梦；
界面风格参考 [pokesurvivor](https://github.com/JPTER78/pokesurvivor)（PMD 蓝色双白边对话框 + 像素精灵），
地图是初代/二代风格的像素道路、森林、山洞与宝可梦之塔。

- **初代 151 只宝可梦**全部登场（79 条进化线）。冒险中击败野生宝可梦，它有几率**崇拜你**、成为新的伙伴（参考宝可梦不可思议的迷宫）
- **闪光宝可梦**：每只宝可梦出现时有 1/1000 的几率是闪光（异色）的，六项能力各高 1%，打倒还没有的闪光宝可梦它一定会崇拜你；
  闪光的和普通的是两只宝可梦，分别培养、分别设为伙伴。研究所的「闪光研究」和火箭队能提高几率，最高 1/200
- **训练家**：小智、小霞初始可选，小刚、小茂、火箭队、坂木老大、娜姿、渡通过成就或星之沙解锁，各有加成，冒险和对战都生效
- **真新镇**：开始游戏后来到可以自由走动的真新镇（《火红 / 叶绿》的原版图块），能看到所有在线玩家和他们跟随的宝可梦；
  冒险、联机、对战、研究所都是镇上的建筑，也可以用右下角的快捷栏或数字键直接打开，不用走到门口
- 一局 20 波：普通波次从 30 秒（第 1 波）逐步增加到 60 秒（第 19 波），**存活到倒计时结束**即可过关；首领波 90 秒
- 第 10 波首领 **卡比兽**，第 20 波最终首领 **梦幻**；第 5/8/12/14/15/17/18/19 波有精英（大针蜂、大岩蛇、耿鬼）
- 技能自动瞄准释放；升级可选强化、**领悟新技能**；等级够了以后波次结束时询问是否**进化**（可以按 B 取消，之后随时再进化）；每波结束后进入**商店**
- **三档难度**：简单 / 普通 / 困难（敌人数量、血量、伤害、移速逐级叠加，并有群聚波与额外精英），通关上一档解锁下一档，**通关困难模式解锁超梦**
- 局外成长：用星之沙在「大木研究所」永久提升所有宝可梦的 HP / 物攻 / 特攻 / 物防 / 特防 / 速度、崇拜几率等
- 通过**崇拜、成就、星之沙**收集宝可梦与训练家，研究所里有 151 格的图鉴
- 联机：在**宝可梦中心**能看到所有公开房间，也可以创建（公开/私密）房间、输入 **5 位房间号**或打开邀请链接加入
- 倒下的队友身边会出现绿色**救援圈**，站进去 2.5 秒就能把它救起来
- 联机冒险中随时可以打开菜单（设置、离开房间）；有人**离开或断线时由 AI 接手**，之后可以**重新连回**房间接着玩
- **道馆**：关都八个道馆（小刚、小霞、马志士、莉佳、阿桔、娜姿、夏伯、坂木），先打道馆训练家再挑战馆主，每个人都有搞笑台词；
  每枚徽章永久提升一项能力和馆主擅长属性的技能伤害，冒险和对战都生效
- **新手引导与过场**：开场由大木博士一步一步引导；第一次来到各个界面时用聚光灯介绍；镇上一直提示「下一步目标」；
  进出建筑、出发冒险、对战开场（VS 画面）、通关与胜负都有过场动画（设置里可以关闭）
- **AI 辅助战斗**：首次通关后解锁，冒险中由 AI 替你走位、躲招、捡糖果，你专心挑技能和道具；战斗中按 `T` 随时切换
- **背包与对战**：每局冒险结束（无论通关与否）都可以把这只宝可梦**放进背包**（12 格，对战场达到超级球级后再多 6 格；满了要放生一只），
  保留等级、形态、技能等级、道具与升级强化。对战场有 **单挑**（双方各派三只同时上场，你操作队长，另外两只由 AI 操作）
  与 **4v4 团战**（每人一只，可以救援）两种排位赛，每场 60 秒、缩圈加时，比的是构筑与阵容；可以随时切换**自动战斗**，
  也可以开局就全部交给 AI 观战（斗蛐蛐）；有积分段位与可视化的对战结算
- **排行榜**：单挑、团战、**冒险**（难度 → 完成波次 → 通关用时）和**道馆**（徽章数）四个榜
- 支持 **Xbox / PlayStation 手柄**（设置里显示手柄是否已连接）

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm run build      # 构建前端 (dist/) 与服务器 (dist-server/)
npm start          # 启动服务器，默认 http://localhost:8787
```

打开浏览器访问 `http://localhost:8787`。单人模式完全在浏览器内运行；「创建房间 / 加入房间」通过同一个服务器联机。
局域网内的朋友访问 `http://你的IP:8787` 即可一起玩。

开发模式（前端热更新 + 服务器自动重启）：

```bash
npm run dev        # 前端 http://localhost:5173 ，/ws 自动代理到 8787 端口的服务器
```

其它命令：

| 命令 | 说明 |
|---|---|
| `npm test` | 单元测试 + 无头整局模拟 + WebSocket 联机集成测试 |
| `npm run typecheck` | TypeScript 类型检查 |
| `npx tsx tools/balance.ts 4 1` | 平衡性报告：机器人用每只精灵各打 4 局（第二个参数为人数） |
| `npx tsx tools/netstat.ts 4 14` | 联机流量报告：进程内跑一局 4 人联机打到第 14 波，统计每位玩家每秒的下行数据（按消息类型）与压缩后的大小 |
| `npx tsx tools/pvp-balance.ts 40 1v1` | 对战平衡报告：机器人先打冒险，在第 5/10/15/20 波存下真实构筑，再按档位组成队伍互相对战，统计对局时长、击倒结束的比例、首次击倒时间、各宝可梦胜率与跨档胜率 |
| `npx tsx tools/gym-balance.ts 30 4` | 道馆难度报告：用上面的构筑缓存组队挑战每个道馆（带着前面的徽章，第二个参数是研究所强化等级），统计各波次档位打赢道馆训练家与馆主的胜率 |

### 部署到公网

> 和中国大陆的朋友联机：卡顿主要来自跨境线路（延迟高、晚高峰丢包），不是服务器性能——这个游戏每个房间的模拟每 tick 不到 1 毫秒，
> 加 CPU 和内存没有帮助。Render 只支持 TCP（WebSocket），没法用 UDP 类的传输。想要更流畅，可以把服务器放到离大陆更近、
> 线路更好的地方，例如香港的云服务器（带 CN2 / 精品网线路更好）；服务器就是一个普通的 Node 进程，直接用仓库里的 Dockerfile 部署即可。

服务器是一个普通的 Node 进程（HTTP 静态文件 + WebSocket `/ws`），任何支持 Node/WebSocket 的平台都可以部署
（Render、Railway、Fly.io、自己的云服务器等）：

```bash
npm ci && npm run build && PORT=8787 npm start
```

也可以用仓库里的 `Dockerfile`：`docker build -t poke-rouge . && docker run -p 8787:8787 -v poke-pvp:/app/data poke-rouge`（`/app/data` 保存对战积分与排行榜）。

如果前端和服务器分开部署（例如前端放静态托管），构建前端时指定服务器地址：
`VITE_SERVER_URL=https://你的服务器域名 npm run build:client`。

环境变量：`PORT`（默认 8787）、`HOST`（默认 0.0.0.0）、`MAX_ROOMS`（默认 300）、`STATIC_DIR`（默认 `dist/`）、
`PVP_DATA`（对战积分与排行榜的保存位置，默认 `data/pvp.json`；用 Docker 部署时请挂载持久卷）、
`PVP_BOT_AFTER`（匹配多少秒找不到真人就由 AI 补位，默认 1v1 12 秒、4v4 18 秒）、
`NET_DROP_BYTES`（服务器进程里待发送的数据超过多少字节就跳过快照，默认 32768）、
`POKE_DEBUG=1`（开启测试用的调试指令，正式部署不要开）。

`GET /api/stats` 返回在线人数（打开着游戏页面的连接数）、游戏中人数与房间数；`GET /api/rooms` 返回公开房间列表；
`GET /api/pvp/leaderboard?mode=1v1|4v4` 返回排行榜前 50 名（冒险榜和道馆榜通过 WebSocket 的 `rankBoard` 查询）。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | `WASD` / 方向键；手机上在屏幕任意位置拖动出现摇杆 |
| 进入建筑 / 和 NPC 说话（真新镇） | 走到门口按 `空格` / `回车`；手机点屏幕下方的提示；手柄 A/× |
| 快速前往（真新镇） | 数字键 `1`~`6` 直接打开冒险 / 联机 / 对战 / 道馆 / 研究所 / 我的家；`M`（手柄 Y/△）打开快速前往菜单；右下角也有快捷栏，左下角的星之沙、宝可梦、徽章、成就也可以点；从这些地方打开的界面关掉后还站在原地 |
| 对话、引导 | 点一下台词立刻显示全部；引导里 `空格` / `回车` 下一步，`Esc` 跳过 |
| 技能 | 自动释放（瞄准最近的敌人） |
| 自动战斗 | `T`、手柄 Y/△ 或点右下角的按钮（对战随时可用；冒险首次通关后解锁） |
| 暂停 / 菜单 | `Esc` / `P` 或右上角的按钮：单人时暂停；联机和对战时打开菜单（设置、离开），游戏不会暂停 |
| 撤销上一次购买（商店） | `Z` |
| 手柄（Xbox / PS） | 左摇杆或十字键移动；菜单和商店里移动选择框，A/× 确认（镇上进入建筑），B/○ 返回或取消进化，X/□ 刷新，Y/△ 出发 / 开始（战斗中切换自动战斗，镇上打开快速前往），LB/RB（L1/R1）翻页与切换标签，LT（L2）撤销购买，Start/Options 暂停（联机和对战时打开菜单，镇上打开设置） |

用手柄操作时，每个按钮旁边会显示对应的手柄键位（自动识别 Xbox 的 ABXY 或 PlayStation 的 ✕○□△），当前选中的元素显示确认键；动一下鼠标或键盘就恢复普通显示。
设置的「手柄」一栏通过 Gamepad API 显示「手柄已连接 / 未连接」和手柄的名字，按下手柄上的键时对应的格子会亮，可以确认手柄是否正常工作。

所有卡片界面都是固定尺寸、等比缩放的：「界面缩放」100% 时最大的界面正好占画面的 90%，可以在 60%~100% 之间调整（数值越大，界面越大；电脑默认 90%，手机默认 100%）；
界面不会滚动，购买、切换宝可梦、房间列表刷新时卡片高度也不会变化，放不下的内容（持有道具、房间列表、排行榜、成就、结算统计等）用分页或标签页显示。
手机需要横屏游玩，竖屏时会提示旋转并尝试全屏锁定横屏。

设置分成「声音」「游戏效果」「画面与性能」「手柄」四组：音效和音乐音量、界面缩放都显示实时的百分比；开关是滑块开关，单选项选中时打勾；
**帧率**可选 30 / 60 / 120 帧（120 帧适合高刷新率屏幕，普通屏幕选了也只显示 60 帧；性能不够时推荐 60 帧，还卡就选 30 帧）；
**画质**可选「高清（原生分辨率）」和「流畅（降低渲染分辨率）」——流畅模式在高分屏上按一半分辨率渲染画面，显卡负担更小，像素画依然清晰。
底部可以一键恢复默认设置，详细说明放在每项旁边的 ⓘ 提示里。

## 游戏设计

### 流程与真新镇

第一次开始游戏时，大木博士会一步一步地问你：先选**训练家**（小智 / 小霞），再起**名字**（可以用推荐的名字），然后选**第一只宝可梦**（妙蛙种子 / 小火龙 / 杰尼龟），
最后确认一遍——上方有步骤条，随时可以返回上一步。然后光圈一收，来到真新镇。
左上角一直显示训练家和跟随的宝可梦；之后的冒险、联机房间和对战都直接使用它们，不用再重复选择。

**引导**：第一次来到真新镇、1 号道路、商店、冒险结算、道馆、对战场、研究所时，大木博士会用聚光灯一步一步介绍界面（看过就不再出现，可以跳过）。
训练家卡片下面一直显示**下一步目标**：第一次冒险 → 把宝可梦放进背包 → 按顺序挑战道馆（队伍等级太低时会提示先去冒险练级）→ 通关 → 在对战场冲段位，点一下直接前往。

**过场**：进出建筑淡入淡出；出发冒险、道馆对战用初代遇敌式的黑色条纹；每场对战前有两位训练家滑进来的 VS 画面；进入新地区时挂出地名牌；
通关、全员倒下、对战胜负先在画面中央显示大字，再淡出到结算。设置里可以关闭过场动画。

| 地点 | 功能 |
|---|---|
| 1 号道路（北边出口） | 选择难度，带着跟随的伙伴出发冒险（出发前也可以换伙伴） |
| 宝可梦中心 | 联机冒险：公开房间列表、创建房间、用房间号加入；房间里显示每个人的训练家与伙伴；中途离开的房间可以从这里回去 |
| 道馆 · 对战场 | 门口的道馆向导问你：挑战道馆（八个道馆，收集徽章），还是去对战场排位（背包里跟随的伙伴当队长，单挑再选两只上场，背包不够时 AI 借你一只） |
| 大木研究所 / 大木博士 | 研究（局外强化）、图鉴（151 格）、成就 |
| 我的家 | 换训练家、招募训练家（星之沙）、改名；宝可梦存储系统里选择跟随的伙伴（「我的精灵」/「全部图鉴」两种浏览方式） |
| 鲤鱼王推销员 | 用 300 星之沙买一只鲤鱼王 |

镇上能看到所有在线的玩家：在镇上的人带着各自的宝可梦走来走去（名字显示在头顶），右上角的在线列表还会显示谁在冒险、对战或联机房间里。
服务器每 0.25 秒推送一次镇上玩家的位置（没有变化就不发）。

**我的家·伙伴**分成两种浏览方式：「我的精灵」只显示已经有的（平时选伙伴、找闪光宝可梦，可以只看闪光的），「全部图鉴」看收集进度（没有的显示剪影和解锁方式）。
右边只放选伙伴需要的简要资料——属性、种族值、进化路线、背包里有没有它的对战构筑——和「让它跟着我」；特性说明和完整的技能表在「详细资料」里。
出发前换伙伴的弹窗也是一样的。

真新镇用的是《火红 / 叶绿》的原版图块：中间是原版的真新镇，上方连着 1 号道路，东边扩建出从常磐市搬来的宝可梦中心与道馆（对战场）；
树冠和屋檐画在人物上面，走到房子后面会被挡住。不想走路时，右下角的快捷栏、数字键 `1`~`5` 或快速前往菜单（`M` / 手柄 Y）可以直接打开各个地方。

### 初代 151 只宝可梦与崇拜

- 79 条进化线覆盖初代全部 151 只。最早设计的 5 条（御三家、皮卡丘、超梦）保留手工调过的数值；其余按图鉴生成：
  - **种族值部分归一化**：按进化阶段把种族值总和往目标值靠拢 70%（三段进化 315 → 410 → 530，两段 330 → 500，单只 470，传说 560），
    弱小的宝可梦（绿毛虫、鲤鱼王……）补强、强大的（快龙、三圣鸟……）削弱，但仍保留各自的特点与数值分布
  - **特性**：每条进化线 1~2 个特性（猛火、毒刺、结实、技术高手、适应力、变身、压迫感……），效果全部数据驱动
  - **技能表**：按属性、物攻/特攻偏好和等级段自动挑选，物攻型的宝可梦也会有远程招式；可达鸭会念力、喵喵会聚宝功、胖丁会唱歌这类专属招式单独指定
  - 只有一种形态的宝可梦在 Lv10 / Lv18 觉醒（全属性 +10%，第二次技能栏 +1）；伊布在商店里买水之石 / 雷之石 / 火之石进化
- 新增约 85 个招式，覆盖虫、飞行、妖精、冰、岩石、地面、幽灵、毒、格斗等属性，现在共有 150 余个技能
- **野生宝可梦乱入**：每波按地区（1 号道路、常磐森林、月见山、宝可梦之塔）乱入 1~4 只野生宝可梦，优先出现还有人没有的；
  后期出现的是进化后的样子。还没有的宝可梦头上有一颗爱心
- **崇拜**：击败野生宝可梦时，它有几率崇拜你，解锁整条进化线（乱入的 10%、宝藏宝可梦 12%、精英 2%、普通小怪 0.25%，再乘以稀有度与崇拜几率加成；首领不会崇拜）。
  联机时击败者已经有了，就让给附近还没有的队友。崇拜会立刻保存，中途离开也不会丢；平均每局能结交 6~8 位新伙伴
- 崇拜几率加成：大木研究所的「友情缎带」（每级 +10%）、小智（+30%）、精灵球 / 超级球 / 高级球 / 大师球；火箭队 -20%
- 部分宝可梦靠成就解锁：皮卡丘（到达第 5 波）、卡比兽（击败卡比兽）、伊布（累计结交 10 位伙伴）、菊石兽与化石盔（完成第 15 波）、

### 闪光宝可梦

- **素材**：初代 151 只的闪光（异色）精灵表全部来自 pokesurvivor 整理的 SpriteCollab 素材（`public/sprites/<图鉴>/s/`），

- **成就**：闪闪发光（第 1 只）、闪光收藏家（5 种）、异色猎人（15 种）、闪耀登场（带着闪光宝可梦完成第 10 波）；每结交一只闪光宝可梦结算时多 30 星之沙

### 战斗数值

- **物理技能**吃「物攻」（偏近身：撞击、火焰牙、藤鞭、铁尾……），**特殊技能**吃「特攻」（偏远程：火花、水枪、十万伏特……），对应土豆兄弟的近战/远程

### AI 辅助战斗

第一次通关（任意难度）后，1 号道路的出发界面会出现「AI 辅助战斗」开关，战斗中也可以按 `T` / 手柄 Y / 右下角的按钮随时切换。
开启后由服务器上的 AI 替你走位：躲开近身的敌人、弹幕、即将落下的攻击和毒雾，保持在技能射程边缘绕圈，安全时去捡糖果、救倒下的队友，血少时去吃树果。
技能本来就是自动释放的；商店、升级、进化和遗忘技能仍由你来选，适合把精力放在构筑上。联机时也可以用，AI 走位不需要上报位置，网络差时更稳定。

### 道馆

关都八个道馆按顺序挑战（快捷栏「道馆」、数字键 `4`，或者走进道馆的门问道馆向导）。用背包里的宝可梦组队，对战方式和单挑一样：三只同时上场，你操作队长，另外两只由 AI 操作，也可以开「自动」整场观战。
每个道馆先要打败一位道馆训练家，再挑战馆主；打败过的道馆训练家下次不用再打。馆主和道馆训练家的队伍是固定的（输了可以研究属性克制再来，道馆向导会提示克制的属性）。
每个人都有开战、输了、赢了的台词，比如小刚会问你有没有姐姐，娜姿三年前就预知你会来所以提前订好了外卖。

道馆界面按挑战前关心的三件事排列：

1. **对手是谁**：馆主、擅长的属性、推荐等级和队伍；台词只在气泡里放一句，点一下用对话框看完整的
2. **我的队伍能不能应对**：出战的三只对馆主属性是克制、被克制还是普通，队伍平均等级够不够，道馆向导的建议；可以直接去背包调整队伍，调整完回到这个道馆
3. **现在能不能开始**：大按钮写明这次的对手（道馆训练家还是馆主）；背包是空的时候引导先去冒险

### 联机

- 服务器权威模拟：每个房间在服务器上跑同一套游戏逻辑，客户端只上报自己的位置与操作；位置有速度校验
- 二进制快照 15 次/秒 + 插值平滑；本地玩家即时移动
- 为跨境 / 高延迟线路做的优化（`tools/netstat.ts` 可以测流量）：
  - 快照和纯视觉的事件（伤害数字、技能特效、爆炸）只发每位玩家视野附近的
  - 波次进行中的私有状态只发 HP、经验、金钱、冷却等变化的字段，整份状态只在真正变化时重发
  - WebSocket 开启 permessage-deflate 压缩
  - 4 人联机第 14 波时，每人下行从约 50 KB/s（压缩前，旧版不压缩）降到约 12 KB/s（压缩后）
  - 流量控制：客户端确认收到的快照编号，服务器据此估计线路上的排队时间；排队超过 150ms 就降低快照频率、只发关键事件，超过 500ms 进一步降低。
    只看服务器进程里待发送的数据量不够——慢线路上的积压大部分堆在操作系统的 TCP 发送缓冲区里，程序看不到
  - 客户端的插值缓冲按快照到达的抖动自动调整（90~320ms）；对局里右上角显示往返延迟，网络不稳定时会提示
  - 在 Chrome 网络模拟里把下行限速到 6 KB/s：旧版本画面会越来越落后（30 秒后落后 14 秒），新版本稳定在 0.5 秒以内
- `GET /api/stats` 的 `perf` 字段是服务器自身的负载：每个 tick 的模拟耗时、事件循环延迟、每秒发出的数据量；
  如果这些数字都很低而玩家仍然觉得卡，问题就在网络线路上
- 敌人数量与血量随人数提升；倒下的队友身边有救援圈，站进去 2.5 秒救起（多人一起救更快），全员倒下才算失败；波次结束时所有人自动复活
- 联机大厅：每个打开游戏的页面保持一条连接，用于统计在线人数和推送公开房间列表；房主可以设为私密房间（只能用房间号加入）
- 房间内最多 4 人，房主选择难度并开始游戏；商店阶段等全员准备（联机时 150 秒后自动开始）
- **菜单、离开与重连**：对局中按 `Esc` / 手柄 Start 或右上角的按钮打开菜单，有「设置」和「离开房间」；联机不能暂停，菜单打开期间 AI 暂时替你战斗。
  - 有人离开或断线时，他的宝可梦由 AI 接手（走位、选升级、逛商店、准备好），队友的队伍栏显示「离开了 · AI 代打中」
  - 加入房间时服务器发一个座位凭证，浏览器保存 2 小时：断线后自动重连，真新镇和宝可梦中心有「回到房间」的入口，刷新页面也能回来
  - 离开期间这局结束的话，回来时补发结算（服务器保留 30 分钟）
  - 所有人都离开时游戏暂停等人回来，5 分钟没人回来就结束这局

### 结算

每局结束会显示可视化的统计：游戏时长、完成波次（20 格进度条，首领波标星）、击败数（小怪 / 精英 / 首领）、
造成与承受的伤害、回复、暴击、闪避、获得与花费的金钱、每波击败数柱状图、各技能的伤害占比（包括已遗忘的技能）、
最终持有的技能与道具（悬停查看效果）、最常击败的宝可梦、进化路线，以及本局获得的星之沙与新成就；联机时还有队伍数据表。

### 背包与对战（PvP）

- **放入背包**：冒险结算界面点「放入背包」，保存这一局结束时的构筑（等级、形态、技能及技能等级、道具、升级卡强化）。
  背包 12 格；在对战场达到**超级球级**（任意模式的最高分 1100）后再多 6 格，掉分也不会收回。满了会弹出放生窗口，对战场的「背包」标签里也可以随时放生
- **对战场**分三个标签：「对战」只做三件事——① 选择模式 ② 确认阵容 ③ 开始对战，右边是自己的段位和最近一场；
  「背包」里看构筑详情（技能、道具）、设队长、选上场的宝可梦、放生；「排行榜」里看四个榜和最近 10 场战绩
- **对战数值受大木研究所影响**：构筑只保存局内成长，开战时再叠加你当前的局外强化（对手同理）
- 设计目标是让养成和对战的时长相称（参考大乱斗的 Smash Run）：辛苦刷出来的构筑不会开场几秒就被秒掉，对战比的是**构筑和阵容搭配**，而不是操作和网速
- **单挑 1v1 = 三对三**：双方各派三只宝可梦同时上场——跟随的伙伴当队长，由你操作，另外两只由 AI 操作，开局锁定不能切换；
  倒下的宝可梦直接退场。背包里不够三只时，AI 会借给你一只比队伍平均低 2 级的宝可梦
- **4v4 团战**：四人一队、每人一只；倒下的队友身边有绿色救援圈，站进去约 3.5 秒救起（35% HP），附近有对手时救援会被打断，对手的救援圈是红色的
- 技能和冒险模式完全一样自动释放，只会打到对手；灼伤/中毒/寄生持续掉血，麻痹/减速/冰冻/畏缩会减速并拖慢技能冷却；物理近身招式会触发对方的反伤与静电
- **每场 60 秒**：15 秒后场地开始缩小（圈外每秒损失 8% 最大 HP），42 秒缩到最小后进入**加时**，伤害逐渐提高到 2.5 倍；
  击倒全部对手获胜，时间到时比较存活数量，再比较剩余 HP
- **防止「秒杀」**：每只宝可梦每秒最多损失最大 HP 的 5.5%（可以攒 14% 的爆发），再强的构筑也要十几秒才能打倒一只；加时里上限逐渐放开。
  对战里的回复效果（再生、吸血、回复招式、寄生种子）减半，加时里继续降低，避免回复型构筑互相拖到超时。伤害还按受击方等级缩放（团战再降低 30%）
- 平衡工具实测（24 条进化线 × 4 个波次档位的真实构筑，单挑三对三）：第 5 波构筑平均 36 秒、第 10 波 41 秒、第 15 波 47 秒、第 20 波 51 秒，
  93%~100% 以击倒结束，没有 20 秒内结束的对局；高一档的队伍对低一档胜率 85%~100%，构筑越强越容易赢。团战平均 38~52 秒
- **自动战斗**：对战中随时按 `T` / 手柄 Y / 右下角的按钮，把队长交给 AI 或切回手动；对战中心的「自动」开关（斗蛐蛐）让队长开局就交给 AI，你只需要观战。
  由 AI 操作时客户端不再上报位置，网络不好也不影响走位
- **匹配**：优先匹配积分接近的训练家，起步 ±100 分、每等 1 秒放宽 25 分；等不到真人时由 **AI 训练家**补位——
  AI 优先使用其他玩家排过队的队伍（强度接近），没有就现场生成；团战按构筑强度蛇形分队，两队实力接近
- **积分与段位**：Elo 积分（初始 1000，前 10 场变化更大，全是 AI 对手时减半），段位
  精灵球级 → 超级球级（1100）→ 高级球级（1250）→ 大师球级（1400）→ 冠军（1600）；中途离开判负
- **排行榜**：1v1 / 4v4 分别排名，显示段位、积分、胜负。还有两个养成的榜，成绩由客户端上报、服务器每人只留最好的一次：
  - **冒险榜**：先比难度，再比完成的波次，都通关时比通关用时（包括商店的时间），一样时先达成的在前；显示当时的伙伴和人数
  - **道馆榜**：先比徽章数，一样多时先拿到最后一枚的在前
- **对战结算**：胜负与原因、积分变化与段位进度、两队剩余 HP 曲线（标出每次击倒）、技能伤害占比（单挑可以逐只查看）、
  双方计分板（伤害、承伤、回复、击倒、救援或退场、队长、MVP）、击倒记录；单挑的统计按自己的三只汇总
- **练习赛**：离线在浏览器里和 AI 对战，不计分；单挑的对手是三只同等级的 AI 宝可梦，团战时队友优先使用背包里等级相近的其他宝可梦
- 对战身份是浏览器里随机生成的一对 ID 与密钥（服务器只保存密钥的哈希），换浏览器/清除存档会变成新的训练家

### 局外成长与成就

- 每局按完成波次、击败数、首领、是否通关结算**星之沙**（联机 +20%）
- 「大木研究所」16 项永久强化（HP、物攻、特攻、物防、特防、速度、暴击、急速、回复、幸运、经验、拾取、开局金钱、商店免费刷新、友情缎带、闪光研究）
- 47 个成就（冒险、收集、联机、道馆、闪光宝可梦），奖励星之沙并解锁宝可梦、训练家与普通/困难难度
- 存档保存在浏览器 localStorage

## 项目结构

```
src/shared/        前后端共用：属性克制、精灵/技能/道具/敌人/波次数据、局外成长与成就、协议、房间
src/shared/sim/    游戏模拟（波次、刷怪、敌人 AI、技能、伤害、升级进化、商店）
src/shared/pvp/    对战：构筑保存与校验、对战模拟（PvpSim）、对战房间、积分与段位、道馆队伍
src/shared/gyms.ts 八个道馆、徽章加成与台词
src/server/        Node 服务器：静态托管 + WebSocket 房间 + 对战匹配与排行榜
src/client/        浏览器端：渲染（像素瓦片、PMD 精灵动画、特效、训练家与真新镇）、HUD、商店与菜单界面、音效
tests/             测试与对局机器人
tools/             素材导入（精灵、真新镇地图、训练家）、平衡性报告
```

素材导入：`node tools/import-sprites.mjs /path/to/pokesurvivor` 会从 pokesurvivor 仓库复制初代 151 只的精灵表（包括闪光宝可梦的）并生成元数据与署名；
`node tools/build-town.mjs /path/to/pokefirered` 用火红 / 叶绿的图块拼出真新镇（输出 `public/town/` 的两层图片与 `src/client/gfx/townMap.ts` 的碰撞、门与 NPC 位置）；
`node tools/import-trainers.mjs /path/to/pokefirered /path/to/pokerogue-assets` 导入训练家的行走图与立绘。这几个工具只用 Node 自带的模块（PNG 的读写在 `tools/png.mjs`）。
图鉴数据在 `src/shared/dex.ts`（种族值、属性、特性、进化族），进化线与技能表由 `src/shared/pokemon.ts` 生成。
